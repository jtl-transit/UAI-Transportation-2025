KEY FEATURES:
─────────────
• Input: Choice sets with J alternatives, each with 4+ features
• Feature Engineering: Advanced features (logs, interactions) + relative features
• Architecture: Deep neural networks with batch normalization and dropout
• Shared vs Separate: One tower shared across alternatives OR separate towers
• Output: Multinomial choice probabilities via softmax activation
• Training: Sparse categorical crossentropy loss with Adam optimizer
